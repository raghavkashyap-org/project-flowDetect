FlowDetect · Short-view

Read 1 → 8, left to right, then the next row. Requests and raw packets converge on the same detection pipeline.

  1. 1. Traffic enters

    A browser, simulator, or external tool sends requests; packet capture also sees raw traffic.

    HTTP / packet input
  2. 2. Ingress & accounting

    FastAPI middleware checks blocked hosts, serves routes, and records request/response activity.

    ASGI · :8000
  3. 3. Assemble flows

    Live request events or captured packets update a shared flow table.

    LiveFlowTable / FlowSession
  4. 4. Build features

    Aggregate timing, packet sizes, flags and rates into the model’s ordered feature vector.

    27 numeric features
  5. 5. Run detection

    The dual-ONNX inference pipeline scores the flow and selects a class.

    Benign · Bot · BruteForce · Flood
  6. 6. Apply alert gate

    A non-benign prediction must pass the confidence gate; host state tracks temporary blocks.

    τ ≈ 0.921056 · block TTL 45 s
  7. 7. Publish live state

    FastAPI broadcasts detections, counters and host state through the live channel.

    WebSocket /ws/live
  8. 8. Show & respond

    The dashboard renders live verdicts; operators can configure, reset, unblock or simulate traffic.

    Frontend :9012 → API :8000

Before traffic · Startup
Load model artifacts, metadata and class order; initialise the engine, flow table, collector and application.

Feedback · Operator controls
Dashboard commands return through :9012 to the API. Simulated traffic re-enters at step 1; configuration and unblock actions update host/engine state.
